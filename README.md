# HyPyP – Hyperscanning Python Pipeline

**Workshop:** Practical MEG/EEG 2025  
**Instructor:** Guillaume Dumas (Université de Montréal)  
**Duration:** 1 hour  

Hands-on workshop on multi-brain hyperscanning analysis (EEG, MEG, fNIRS).

## Installation

**Requirements:** Python 3.10+ and Poetry

```bash
# Install dependencies
poetry install

# Launch Jupyter
poetry run jupyter lab
```
